## 1. 简短说明（Chrome ≤ 132 字符 / Edge 由 manifest 的 description 决定）

```
Serein 新标签页：可自定义的图标网格 + 文件夹，附时钟、搜索、天气、待办与便签。零依赖、无账号，数据只存本地，图标链接永不被改写。
```

`manifest.json` 里当前这句已经满足；如果改这里，记得同步 manifest 的 `description`（Edge 的简短说明取自它）。

## 2. 详细说明（Edge 要求 ≥ 250 字符）

```
Serein 把「新标签页」当成工作台：打开就是时钟、搜索、常用站点、天气和待办，全部可改，全部只存在你自己的浏览器里。

【首屏】
· 大号时钟：24/12 小时制，可显示秒，可关闭
· 日期 + 星期 + 农历 + 节日
· 搜索框：多引擎切换、网址直开、本地快捷方式匹配、输入「设置」「壁纸」「布局」直达命令
· 搜索联想：Google / 必应 / 百度 / 360 / DuckDuckGo / 哔哩哔哩，匹配词高亮，最近搜索只存本机
· 完整键盘操作：Ctrl/Cmd + K 聚焦搜索，方向键移动，Enter 打开，F2 编辑，Delete 删除

【快捷方式】
· 图标网格：列数、图标大小、列距行距全部可调，末行自动居中
· 内置 80 个矢量品牌图标，离线可用，任意尺寸都清晰
· 文件夹：拖入拖出，磁贴内 2×2 缩略预览
· 拖拽排序，快捷方式与文件夹可任意交错
· 右键菜单：打开、编辑、移动到文件夹、新建文件夹并移入、删除
· 删除可撤销（6 秒内点提示条上的「撤销」）

【壁纸与外观】
· 壁纸来源：渐变预设、必应每日一图、图片链接、本地上传、纯色
· 必应壁纸可回看最近 8 天
· 六套视觉风格：轻玻璃、暗色材质、白纸、原色、编辑排版、终端
· 毛玻璃强度、圆角、强调色、模糊/亮度/饱和度/暗角、界面缩放、动效开关
· 文字色调自动判定：浅色壁纸上自动切成深色文字

【小组件】
· 天气：当前温度、体感、湿度、未来 5 天（Open-Meteo，无需 Key）
· 待办：勾选、删除、清除已完成
· 便签：自动保存，卡片弹性撑满侧栏
· 书签 / 常去网站：按需申请权限，不授权就不出现

【数据与隐私】
· 没有账号，没有服务器，没有云端同步
· 不收集任何浏览数据，不上传统计
· 配置与快捷方式随时导出 / 导入 JSON
· 永远不会把图标链接改写成推广链接
· 常驻权限只有 storage、unlimitedStorage、favicon

零依赖、零构建、纯静态 MV3 扩展，源码可读，改一行 CSS 就能换风格。
```

## 3. 单一用途（Single purpose）

```
把浏览器的新标签页替换成一个可自定义的快捷方式面板：图标网格与文件夹，配合时钟、搜索、天气、待办、便签等小组件。
```

---

## 4. 权限理由（逐条粘贴）

| 权限 | 理由 |
|---|---|
| `storage` | 保存快捷方式、文件夹、布局与外观等配置到本机，不涉及任何上传。 |
| `unlimitedStorage` | 用户上传的壁纸与自定义图标存放在 IndexedDB 中，二进制资产容易超过浏览器默认的存储配额。 |
| `favicon` | 使用浏览器内置的 `_favicon` 接口读取本地已缓存的网站图标作为快捷方式图标，不发起任何网络请求。 |
| `bookmarks`（可选） | 仅在用户主动点击「从书签批量导入」时申请，用于把本地书签一次性转成快捷方式。 |
| `topSites`（可选） | 仅在用户主动开启「常去网站」小组件时申请，用于读取浏览器本地统计的常访问站点。 |
| `https://cn.bing.com/*` | 用户把壁纸设为「必应每日」时，请求当日壁纸元数据与图片。 |
| `https://api.bing.com/*` | 搜索联想开启且使用必应引擎时，请求输入词前缀的联想结果。 |
| `https://suggestion.baidu.com/*` | 搜索联想开启且使用百度引擎时，请求输入词前缀的联想结果。 |
| `https://sug.so.360.cn/*` | 搜索联想开启且使用 360 引擎时，请求输入词前缀的联想结果。 |
| `https://suggestqueries.google.com/*` | 搜索联想开启且使用 Google 引擎时，请求输入词前缀的联想结果。 |
| `https://duckduckgo.com/*` | 搜索联想开启且使用 DuckDuckGo 引擎时，请求输入词前缀的联想结果。 |
| `https://s.search.bilibili.com/*` | 搜索联想开启且使用哔哩哔哩引擎时，请求输入词前缀的联想结果。 |
| `https://api.open-meteo.com/*` | 天气小组件读取当前天气与 5 日预报。 |
| `https://geocoding-api.open-meteo.com/*` | 城市选择器里按关键词搜索城市，拿到经纬度后交给天气接口。 |

补充说明（可填在备注里）：

```
所有 host 权限都只在用户主动使用对应功能时才会发出请求；搜索联想和天气都可以在设置里关闭。扩展没有账号、没有服务器、不收集任何用户数据，也不使用远程代码。
```

## 7. 认证测试说明（Chrome "Test instructions" / Edge "Certification notes"）

```
打开新标签页即可看到全部功能，无需账号、无需 API Key、无需任何配置。

功能自查路径：
1. 新标签页 → 时钟、搜索、图标网格、右侧小组件
2. 右键任意图标 → 打开 / 编辑 / 移动到文件夹 / 删除
3. 右键空白处 → 添加快捷方式 / 新建文件夹 / 更换壁纸 / 调整布局 / 设置
4. 设置（Ctrl+,）→ 外观（六套风格）、壁纸（含必应每日）、布局、数据
5. 设置 → 数据 → 导出 JSON 备份

说明：
· 天气与搜索联想需要联网；断网时天气显示占位文案，不会报错或崩溃。
· bookmarks / topSites 为可选权限，只在用户主动点击「从书签导入」「常去网站」时才会弹窗。
· 所有数据保存在本机 localStorage / IndexedDB，卸载扩展即清除。
```
