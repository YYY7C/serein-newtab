# 路线图与未完成事项

当前版本：**V1.5.1**（2026-11-23）
已完成内容的详细记录见 [CHANGELOG.md](../CHANGELOG.md)；这里只列**还没做**、**做得不够**、以及**已知限制**。

标记说明：`P2` = 下一阶段，`P3` = 有空再说，`BLOCKED` = 受浏览器或第三方接口限制。

---

## 一、未完成的功能

### 1. 跨设备同步（P2）

- WebDAV 同步：用户自填地址/账号，或直接支持坚果云、Nextcloud。
- 端到端加密：用 WebCrypto（AES-GCM + PBKDF2/Argon2 不可用则 PBKDF2）在本地加密后再上传，服务器只看到密文。
- 冲突策略：先做「按实体 revision + 最后编辑者胜」，再做快捷方式/待办级别的三方合并。
- 复用现有 `buildBackup()` 的 zip 结构，避免第二套序列化格式。
- 需要的 UI：设置 → 数据 → 同步（地址、账号、密码、立即同步、上次同步时间、清除远端）。
- 风险：CSP 与 `host_permissions` 无法预知用户的自建地址，需要 `optional_host_permissions` + 运行时申请。

### 2. 多标签页并发写入的按实体合并（P2）

- 现在是「最后编辑者胜」：两个标签页同时改不同快捷方式时，后写的一方会覆盖前者。
- 计划：每个实体带 `rev`，合并时按 id 取较新版本，删除用 tombstone（`deletedAt`）保留 7 天。
- 需要先补并发测试：两个页面同时 `addShortcut` / `removeShortcut`，断言两边最终一致。

### 3. Firefox 构建（P2）

- 需要处理 `background.service_worker` → `background.scripts`、`chrome_url_overrides` 兼容、`_favicon` 不可用时的降级。
- 建议用独立目录 `dist-firefox/` + 构建脚本改写 manifest，保持 `src/` 单一来源。
- `chrome.permissions.request` 在 Firefox 中是 `browser.permissions.request`，需要 polyfill 或 `globalThis.browser ?? chrome`。

### 4. 国际化（P2）

- 目前文案全部硬编码中文（`defaults.js`、`settings.js`、`widgets.js`、`search.js`、`modals.js`）。
- 计划：`_locales/zh_CN` + `_locales/en`，运行时用 `chrome.i18n.getMessage`，HTML 里用 `__MSG_*__`。
- 先抽离 UI 文案常量，再逐模块替换；`docs/` 与商店文案单独维护。

### 5. 模块拆分（P2）

- `settings.js`（约 2.3k 行）、`tiles.js`（约 1.2k 行）、`search.js`（约 1.4k 行）偏大。
- 目标：`settings/` 目录按分区拆成 `appearance.js` / `wallpaper.js` / `layout.js` / `search.js` / `widgets.js` / `data.js` / `about.js`，由 `settings/index.js` 组装。
- 拆分前先把「读 store + 触发 touch」收敛成显式上下文参数，避免闭包耦合。
- 必须保持零构建：直接用原生 ES Module 动态导入。

### 6. 命令面板（P3）

- 命令结果支持自定义排序/置顶；记录「最近执行的命令」。
- 支持 `>` 前缀只显示命令、`@` 前缀只显示标签页，降低歧义。
- 书签搜索目前复用 `bookmarks` 权限；如果用户只想要命令面板、不要小组件，仍需为「搜索书签」单独引导一次授权说明。
- 历史搜索的隐私开关还没有独立项（关闭后仍可命令面板搜索）；建议加「允许命令面板读取历史」开关。

### 7. 壁纸（P3）

- 本地壁纸池没有排序/拖拽；轮换顺序固定为添加顺序。
- 没有裁剪/焦点选择（object-position），竖图在超宽屏上会裁掉主体。
- 没有按主题自动切换深/浅壁纸池。
- 轮换只在打开新标签页时判断，长时间开着的标签页不会按时自动换图。

### 8. 自定义 CSS（P3）

- 编辑器没有语法高亮、括号匹配、错误提示；写错只会在控制台静默失败。
- 没有内置示例/片段库（隐藏时钟、改网格间距等）。
- 只移除 `@import` 与 `expression(`，没有阻止 `url(https://…)` 的远程请求（属于用户主动行为，已在文档说明）。

### 9. 自定义字体（P3）

- 只支持单文件单字重；不解析 `@font-face` 的 weight/style，粗体仍会用合成加粗。
- 没有字形子集化，中文 TTF 常见 5–20 MB，容易触发 8 MB 上限；可考虑接入 `fonttools` 之类的离线脚本（不引入运行时依赖）。
- 上传后不会提示「字体不含中文」这类覆盖不全的问题。

### 10. 小组件（P3）

- 专注计时只有 25/5 固定时长，不能自定义，也没有长休息与轮次统计。
- 专注结束只发 toast，没有声音/系统通知（通知需要额外权限）。
- 世界时钟城市列表固定 12 个，不能搜索任意 IANA 时区。
- 倒计时只支持一个，不能保存多个事件。
- 所有秒级计时器在页面隐藏时仍会触发（浏览器会节流），可统一成单个 `requestAnimationFrame`/可见性感知的 ticker。

### 11. 备份（P3）

- 全量导出，没有增量/选择性导出（只导快捷方式、只导待办）。
- 没有自动定时备份到下载目录（浏览器扩展不便直接写文件）。
- zip 读取只支持自己生成的结构（store/deflate、无 zip64、无加密），用户用系统压缩工具重新打包后可能读不了。

## 二、已知限制（BLOCKED / 设计取舍）

| 限制 | 原因 | 影响 |
|---|---|---|
| 多标签页为最后编辑者胜 | 未实现实体级合并 | 同时编辑不同条目可能互相覆盖 |
| `_favicon` 依赖 Chrome/Edge | Firefox 无此 API | 网站图标模式在 Firefox 需降级为品牌图标/字符 |
| 必应壁纸、Open-Meteo 条款 | 第三方公开接口 | 商业使用需自行确认授权；接口变更会失效 |
| 无痕窗口 | 浏览器限制 | 扩展默认不启用，或每次都是空配置 |
| `color-mix()` 需 Chrome/Edge 116+ | CSS 新特性 | `minimum_chrome_version` 已设为 116 |
| 紧凑密度仍可能滚动 | 内容确实超过一屏 | 极小窗口（<1100×600）下侧栏需要滚动 |
| 自定义 CSS 可破坏可访问性 | 用户自定义 | 不拦截，只在文档提示 |
| 自定义字体失败会静默回退 | 避免坏文件阻塞首屏 | 用户可能不知道为什么没生效（设置页显示「当前：文件名」） |
| 命令面板标签页/历史搜索 | 依赖可选权限 | 本地预览与未授权时不可用（已明确提示） |
| 备份导入整包替换 | 简单可靠优先 | 不能与现有数据合并 |
