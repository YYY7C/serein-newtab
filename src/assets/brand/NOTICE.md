# 品牌图标来源与使用说明

`src/assets/brand/` 下是 Serein 内置的站点图标。它们只用于「在快捷方式上标明这是哪个网站」，
不表示与该品牌存在任何关联、赞助或背书。

## 来源

| 类别 | 图标 | 来源 / 许可 |
| --- | --- | --- |
| 单色字形 | baidu、bilibili、zhihu、github、youtube 等约 70 个 | 取自 [Simple Icons](https://simpleicons.org)，该图标集以 **CC0 1.0** 释出；本项目把它们重新排进 48×48 的白底方块，并按各品牌官方色上色 |
| 多色 / 手绘 | `google`、`figma`、`instagram`、`microsoft`、`bing`、`jd`、`douyin`、`deepseek`、`sspai` | 本项目按品牌公开标识自行绘制的简化几何图形；`sspai` 的字形取自少数派官网首页内联 SVG 标识 |

## 商标

所有品牌名称、标识与商标归各自所有者所有。这里的图形仅作为「指向该站点的书签」使用，
属于指明来源的合理使用。若你是权利方并希望移除某个图形，提一个 issue 即可，我们会尽快删除。

## 维护方式

图标 SVG 已按最终形态入库，运行时直接引用，不需要构建或生成步骤。
新增图标时按同样的 48×48 白底方块规格补一个 `<slug>.svg`，再到 `assets/js/brands.js` 登记域名即可。

## 未收录的站点

没有内置图标的站点会自动退回 Chrome 本地缓存的站点图标（`favicon` 权限），
再退回按域名生成的品牌色字符徽标，因此离线也不会出现空白方块。
